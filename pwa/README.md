# PWA Module

โฟลเดอร์นี้รวบรวมไฟล์ทั้งหมดที่เกี่ยวข้องกับระบบ Progressive Web App (PWA) ถูกแยกออกมาเพื่อไม่ให้ปะปนกับระบบหลัก

## ไฟล์ภายในประกอบด้วย
- `manifest.json`: ไฟล์กำหนดคุณสมบัติของ App เช่น ชื่อ, ไอคอน, สี, และหน้าเริ่มต้น (`start_url: "../index.html"`)
- `pwa.js`: สคริปต์ตัวจัดการ (Manager) ที่ใช้ลงทะเบียน Service Worker
- `icons/`: โฟลเดอร์เก็บไอคอนสำหรับแพลตฟอร์มต่างๆ

## ⚠️ Service Worker (`sw.js`)
เพื่อให้ PWA สามารถแคชและทำงานออฟไลน์ได้ทั่วทั้งแอป ไฟล์ `sw.js` จำเป็นจะต้องอยู่ที่ **Root Directory (`/sw.js`)** ของโปรเจกต์ เนื่องจาก GitHub Pages ไม่อนุญาตให้เปลี่ยน Scope นอกโฟลเดอร์ของไฟล์ Service Worker (เช่น ถ้าเอาไว้ใน `/pwa/sw.js` มันจะแคชได้เฉพาะไฟล์ใน `/pwa/` เท่านั้น)

## วิธีเปลี่ยนไอคอน
1. นำไฟล์รูปภาพ .png ของคุณมาใส่ในโฟลเดอร์ `/pwa/icons/`
2. แก้ไขไฟล์ `/pwa/manifest.json` ให้ชี้ไปที่รูปภาพใหม่ของคุณ

## วิธีการล้างแคช (กรณีหน้าเว็บไม่ยอมอัปเดต)
สคริปต์ `sw.js` ใช้เทคนิคผสม:
- Network-first สำหรับไฟล์ HTML (อัปเดตทุกครั้งถ้ามีเน็ต)
- Stale-while-revalidate สำหรับ CSS, JS, รูปภาพ (โหลดของเก่าก่อน แล้วอัปเดตเบื้องหลัง)

หากต้องการล้างแคชจริงๆ ให้แก้ไขตัวแปร `CACHE_VERSION` ในไฟล์ `/sw.js` ให้เป็นค่าใหม่ (เช่น `v2`, `v3`) แล้วรีเฟรชหน้าเว็บ
