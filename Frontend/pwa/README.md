# PWA Module

โฟลเดอร์นี้รวบรวมไฟล์ทั้งหมดที่เกี่ยวข้องกับระบบ Progressive Web App (PWA) ถูกแยกออกมาเพื่อไม่ให้ปะปนกับระบบหลัก

## ไฟล์ภายในประกอบด้วย
- `manifest.json`: ไฟล์กำหนดคุณสมบัติของ App เช่น ชื่อ, ไอคอน, สี, และหน้าเริ่มต้น (`start_url: "../"`)
- `icons/`: โฟลเดอร์เก็บไอคอนสำหรับแพลตฟอร์มต่างๆ (`icon-192.png`, `icon-512.png` ใช้ติดตั้งแอป)

## ⚠️ Service Worker (`sw.js`)
เพื่อให้ PWA สามารถแคชและทำงานออฟไลน์ได้ทั่วทั้งแอป ไฟล์ `sw.js` จำเป็นจะต้องอยู่ที่ **Root Directory (`/sw.js`)** ของโปรเจกต์ เนื่องจาก GitHub Pages ไม่อนุญาตให้เปลี่ยน Scope นอกโฟลเดอร์ของไฟล์ Service Worker (เช่น ถ้าเอาไว้ใน `/pwa/sw.js` มันจะแคชได้เฉพาะไฟล์ใน `/pwa/` เท่านั้น)

## วิธีเปลี่ยนไอคอน
1. นำไฟล์รูปภาพ .png ของคุณมาใส่ในโฟลเดอร์ `/pwa/icons/`
2. แก้ไขไฟล์ `/pwa/manifest.json` ให้ชี้ไปที่รูปภาพใหม่ของคุณ

## วิธีการล้างแคช (กรณีหน้าเว็บไม่ยอมอัปเดต)
สคริปต์ `sw.js` ใช้ cache-first กับไฟล์หน้าเว็บทั้งหมด รวม library ใน `/vendor/` ส่วน `/api` ไม่ถูกแคช

ทุกครั้งที่แก้ไฟล์ใน `APP_SHELL` ให้เพิ่มเลขเวอร์ชันของ `CACHE_NAME` ในไฟล์ `/sw.js` หน้าเว็บที่เปิดอยู่จะโหลดใหม่เองหนึ่งครั้งเมื่อ Service Worker ตัวใหม่เริ่มทำงาน ไฟล์ library ใน `/vendor/` คัดลอกมาจาก npm: jsqr@1.4.0 (`dist/jsQR.js`) และ @simplewebauthn/browser@14.0.0 (`dist/bundle/index.umd.min.js`)
